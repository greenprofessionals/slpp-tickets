Event Configuration

Set the branding, pricing, and details that power every ticket.

What this form actually controls

This is the single source of truth for the whole ticketing system. Whatever's submitted here becomes the live configuration immediately — no code changes, no redeploying, nothing else to touch.

  • Event branding — organization name, chapter name, event title, tagline, date, time, venue, dress code, contact info, and website link
  • Ticket tiers — up to 5 tiers, each with its own name and price (Single, Patron, Double, or anything else this event needs)
  • Chapters or groups — the full list guests choose from, or turned off entirely if this event doesn't need that concept
  • Logo & background image — upload directly in the form; both appear automatically on every generated ticket
Submitting this form again later doesn't create a duplicate configuration — the most recent submission always wins, so updating the event just means filling it out again with the new details.
